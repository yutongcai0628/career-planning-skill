# 职场规划导师 skill — 编辑指南（README）

> 这份 README 是给**人**看的，帮你快速找到"想改某个行为该动哪个文件"。
> Claude 运行时**不读**这个文件，它读的是 `SKILL.md` 和按需加载的 `references/`。

## 这个 skill 是干什么的
扮演一位职业规划导师，帮用户做职场规划。三个核心场景：
1. **能力点挖掘**（刚入职场 / 迷茫，挖兴趣和能力）
2. **中期规划**（大厂vs创业 / 打造核心竞争力 / 路径构建）
3. **岗位分析**（给一段 JD，分析适不适合 + 该怎么规划）

两个让它区别于普通聊天的"硬动作"：① 用**选择题**（`AskUserQuestion`）挖掘，而不是让用户写小作文；② 用**图表**（`mcp__visualize__show_widget`）把结论画出来。

### 持续档案（跨对话记忆 · 职业笔记系统）
本 skill 会为每个用户维护一份会持续生长的职业档案，每次开场先读、收尾更新，从而"越用越懂你"。两种存储模式：
- **本地 Markdown（默认）**：存在当前目录 `职业档案/` 文件夹，零依赖、人人可用。
- **飞书文档（可选）**：装了飞书 lark skills 时，档案可存成飞书云端文档，用户随时在飞书 App 里翻看、自己也能编辑——真正的"职业笔记系统"。靠本地 `职业档案/飞书档案.txt` 记住文档链接。
- 隐私：`职业档案/` 已被根目录 `.gitignore` 忽略，**开源 push 不泄露**；skill 本体不含任何人的数据。

`SKILL.md` 是入口，它在合适的时候用 `references/xxx.md` 这样的指针把对应文件"按需加载"进来——所以改方法论去对应 reference，改整体行为去 SKILL.md。

## 改之前要知道的几件事

- **`description`（SKILL.md 第 3 行）决定触发**。Claude 靠它判断"用户这句话要不要用本 skill"。想让它在更多/更少场景触发，就改这里的关键词。
- **`AskUserQuestion` 有硬限制**：一次最多 4 题、每题最多 4 个选项。改题库时别超（详见 `交互与可视化.md` 开头的提醒）。
- **图表用 CSS 变量上色**（如 `var(--text-primary)`），不要硬编码颜色，否则深色模式看不见。模板和规范都在 `交互与可视化.md`。
- 改完**直接生效**，不用重启——下次触发就是新版本。

## 怎么测试改动有没有效果
在本目录开 Claude Code，说一句会触发的话（如"我想做职场规划""帮我看看这个 JD"），看它的提问和出图是不是你想要的。觉得不对就回来接着改。
