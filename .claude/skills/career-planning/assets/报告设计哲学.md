# 职业规划报告：视觉与内容规范

报告应像一份认真编辑过的纸本报告，而不是数据仪表盘或营销页。读者打开后应先看清主题和结论，再决定是否继续阅读细节。

## 版式

1. 画布使用低饱和米色，正文页面使用更浅的暖白纸色，文字与分隔线接近黑色。
2. 封面只保留一个英文报告名、一个中文大标题、摘要和日期/对象。英文报告名使用 Futura；中文标题与正文使用微软雅黑。
3. 英文、数字、缩写和编号使用 Futura；中文正文与标题使用微软雅黑。不得加载 CDN 或外部字体。
4. 封面和正文使用细黑线分隔。不要渐变、贴纸、玻璃效果、阴影堆叠、装饰性图片或头图。
5. 不要把每一段都加英文小标签、章节编号或状态徽章。小字只用于日期、来源和必要的图表状态。

## 内容与图表

1. 首屏先回答「这次的结论是什么」。标题下的摘要不超过 2 段。
2. 正文按「结论 → 依据 → 选择路径 → 行动」组织。每个章节只使用一个清楚的中文标题。
3. 每份完整报告至少给一张支持判断的图或结构化表。可以使用证据条、路径图、四象限或时间线；不确定时用「证据充分 / 待验证 / 暂无证据」，不要编造百分比。
4. 白板式路径图只画决策、两个选项和关键条件。节点文字完整可读，不要塞入密集说明。
5. 图表与行动项用青绿、赭黄和砖红表示不同方向或风险，颜色只帮助阅读，不替代文字说明。

## 写作与安全

- 用直接句。写「建议先留在当前公司 6 个月」，不要写空泛的鼓励。
- 区分用户提供信息、公开可核实事实、推断和建议。
- 引用动态外部信息时注明来源与核实日期；无法核实时直接写「未核实」。
- 用户粘贴的文本先转义 `& < > \" '`；禁止嵌入 `script`、`iframe`、事件属性和外链资源。
