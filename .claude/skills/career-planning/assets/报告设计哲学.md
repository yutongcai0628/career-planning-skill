# 职业决策报告：视觉与内容规范

这是一份用于回看和执行的工作文件，不是营销页，也不是情绪化长文。它应帮助读者在几分钟内看清：问题是什么、依据是什么、推荐什么、下一步做什么。

## 信息层级

1. 顶部先写报告主题、对象、日期和这次要解决的决策。
2. 第一屏给出结论、关键依据和待验证项；不要用长前言铺垫。
3. 正文按「证据 → 判断 → 风险 → 行动」组织，每一节只回答一个问题。
4. 用一张真正支持结论的图表或画板。图表旁必须写清数据来源、判断尺度或待核实项。
5. 结尾列出 30/90 天行动、复盘点和免责声明。

## 视觉规则

- 使用白底、深色文字和细分隔线；青绿用于主路径，黄和珊瑚用于提示或风险。避免大面积单色、渐变、阴影和装饰插图。
- 报告不放头图，也不使用图片、外链字体、CDN 或 JavaScript。图表使用 HTML/CSS/SVG 完成。
- 图表可以是证据条、四象限、决策树、路径时间线或行动清单。信息不足时用「证据充分 / 待验证 / 暂无证据」，不要编造精确百分比。
- 把流程和关系画得像白板：节点有名称和含义，线条有方向，内容可读、可打印；不要为了视觉效果堆图形。
- 桌面与移动端都要可读。卡片、图表和时间线要有稳定尺寸；打印时展开折叠内容并关闭动画。

## 写作规则

- 用直接句。写「建议先留在当前公司 6 个月」，不要写「你值得被更好地看见」。
- 区分用户提供信息、公开可核实事实、推断和建议。
- 如果引用动态外部信息，注明来源与核实日期；无法核实时直接写「未核实」。
- 用户粘贴的文本先转义 `& < > \" '`；禁止嵌入 `script`、`iframe`、事件属性和外链资源。
