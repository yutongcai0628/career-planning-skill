# 导出报告（把规划交付成正式文档）

让规划不只停在对话里，而是交付成一份**能保存、能分享、看起来很专业**的文档。这是把 skill 从"聊天"提升到"咨询产品"的一步。

## 何时提出导出
给完一份完整规划后，主动问一句"要不要我帮你导出成一份正式报告？"；或用户说"生成报告/导出/存成文档/做成 PDF/写到飞书"时立即执行。

用 `AskUserQuestion` 让用户选格式（选项 ≤4）：
- **HTML 精美报告**（推荐，自带样式、内嵌图表、可直接打印成 PDF）
- **PDF 报告**
- **飞书文档**（需装了飞书 lark skills）
- **Markdown**（朴素、通用）

## 各格式怎么做

### 1. HTML 精美报告（默认、自包含、人人可用）
1. 读取模板 `assets/报告模板.html`。
2. 替换 `{{NAME}}`（用档案里的名字）、`{{DATE}}`、`{{TAGLINE}}`（一句话概括这个人，如"给一个会增长、敢露脸的内容创作者"）。
3. 把 `<!-- CONTENT -->` 区域换成本次规划正文，照模板里给的 `section / callout / chart-card / ol.actions` 结构写。
4. **图表**：把本次生成的 SVG 直接粘进 `.chart-card`。注意——独立 HTML 里**没有** widget 的 CSS 变量，必须把 SVG 里的 `var(--xxx)` 换成固定色（参考模板 `:root` 里的色值：主色 `#4338ca`、文字 `#1b1b2b`、次要 `#5b5b6e`、边线 `#e7e7ee`、成功/警告/危险 `#0f766e`/`#b45309`/`#b91c1c`），否则会变黑或透明。
5. 写到 `职业档案/报告/职业规划报告-<名字>-<日期>.html`，然后 `open` 它，并告诉用户："已生成，浏览器里打开了；想要 PDF 直接在页面上 Cmd+P → 存为 PDF，排版已经为打印优化过。"

### 2. PDF 报告
最稳的方式就是**先生成上面的 HTML，再转 PDF**：
- 首选让用户在打开的 HTML 页面里 `Cmd+P → 存储为 PDF`（模板已写了打印优化的 `@media print`）。
- 若环境里有 Chrome/Chromium，可命令行直接转：
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --print-to-pdf="职业档案/报告/报告.pdf" --no-pdf-header-footer "职业档案/报告/xxx.html"`（路径按实际改）。
- 也可改用 `anthropic-skills:pdf` 这个 skill 来生成/处理 PDF。
不要硬造一个脆弱的 PDF 流程——HTML→打印 是最可靠的。

### 3. 飞书文档（可选，装了 lark skills 才用）
**先判断有没有飞书能力**：可用的技能列表里是否有 `lark-doc` / `lark-drive` 等。没有就告诉用户"你还没装飞书 skill，我先给你 HTML/Markdown 版"，优雅跳过，别报错。
有的话：
1. 把规划正文整理成 **Markdown**。
2. 调用 `lark-doc` skill（创建文档，携带 `--api-version v2`，可用 Markdown 内容）把报告写成一篇飞书云文档；或用 `lark-drive` 把本地 Markdown 导入为飞书 docx。
3. **图表用飞书画板呈现（这是飞书版报告的招牌）**：报告里的三圈图、路径图、四象限、匹配度图，用画板落进文档——简单图直接在 XML content 里内嵌 `<whiteboard type="svg">完整 SVG</whiteboard>`（SVG 复用 `交互与可视化.md` 模板，CSS 变量换成固定色）；复杂图先建 `<whiteboard type="blank">` 再按 `lark-whiteboard` skill 填充。画板插入失败就退回文字/表格标注"详见 HTML 版图表"，别因为图卡住整个流程。
4. 把生成的文档链接回给用户。

### 4. Markdown（兜底）
直接把规划正文写成 `职业档案/报告/职业规划报告-<名字>-<日期>.md`。图表用一句话描述或附 HTML 版链接。永远能用，零依赖。

## 隐私
报告含个人数据，统一存在 `职业档案/报告/` 下——该目录已被根目录 `.gitignore` 忽略，开源 push 不会泄露。

## 原则
- **内容复用**：报告正文就是你刚在对话里给的规划，别重写一版、别注水，把对话里的判断/分析/建议/行动原样结构化即可。
- **图表带上**：有图的话一定放进报告，这是"高级感"的关键。
- **一次只做一种**：用户选哪种做哪种，做完给路径/链接，别一次全导。
