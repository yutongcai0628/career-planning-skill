# 能力点挖掘（职场早期 / 方向迷茫）

适用对象：刚入职场、应届、或工作没几年还没想清楚方向的人。

核心信念：**专业决定不了你的天花板。先从兴趣出发，再把兴趣磨成擅长。** 很多人卡在"我学的是 X，所以只能做 X"，或"我不知道自己喜欢什么、擅长什么"。你的任务是带他走这条链：**挖出真实兴趣 → 顺着兴趣找到能力点 → 用小实验验证 → 不断迭代**。兴趣是种子，能力是从持续投入里长出来的——"擅长"几乎都是"喜欢到愿意投入足够多"的结果。

## 一、先把"三个圈"分开
迷茫常因为把三件事混成一团，先帮用户分清：
- **想做（兴趣）**：做什么会忘记时间、主动想做、聊起来眼睛发亮。
- **能做（能力 / 天赋）**：学得比别人快、做着不累、容易进入心流、常被夸、别人会来找你帮忙。
- **值得做（价值 / 回报）**：市场愿意付钱、有空间、符合价值观。

理想职业在三圈交集。但早期不必强求——**先把"想做 × 能做"找扎实，"值得做"靠后续路径去靠近**。最忌只盯"值得做"（钱多/热门）去选，结果既不喜欢也不擅长。

## 二、先挖兴趣：从"行为线索"推断，别直接问
**不要问"你的兴趣是什么"**——很多人答不上来，或把"消遣"（刷剧躺平）误当兴趣。真实兴趣藏在行为里，用下面的线索去钓（可配合 `交互与可视化.md` 题库 B/C 做成选择题）：
- 你会**主动花时间 / 花钱**在什么上？哪怕没人要求、没有回报。
- **收藏夹、浏览记录、关注列表**里反复出现什么主题？
- 和别人聊什么会**停不下来、忘记时间**？
- 你**羡慕谁**的工作或生活？羡慕往往暴露你真正想要的东西。
- 不被评价、没人看时，你喜欢做什么？小时候呢？
- 什么事你**愿意连它枯燥的部分都钻进去**？（这条最关键，见下）

**两种典型困境的处理：**
- **"我对什么都没感觉。"** 多半不是没兴趣，而是 (a) 长期被"应该"压住、接触得太少；(b) 把标准定太高（以为兴趣要热血沸腾）。解法：**降低标准**——"哪个稍微没那么讨厌、有点好奇"就够当起点；并去**制造更多输入**（多接触、多试），兴趣常常是接触出来的，不是凭空想出来的。
- **"我什么都三分钟热度。"** 区分"喜欢学新东西的开头"和"愿意熬过枯燥的中段"。能长成能力的兴趣，是那个**你愿意忍受它无聊部分**的——用这把尺子去筛，而不是看哪个开头最兴奋。

## 三、顺着兴趣，反推能力点
锁定兴趣方向后，**用选择题 + 追问把能力点钓出来**（迷茫的人认得出、却回忆不出自己擅长什么）。除了题库，下面几个角度的"为什么"也值得顺着追：
- **成就感事件**："有没有一个具体高光瞬间？当时你做对了什么？"
- **轻松区**："有没有什么别人觉得难、你却随手就做了？"——天赋常在这，因为对自己太容易，本人反而不当回事。
- **被求助模式**："朋友/同事默认你擅长什么、会因为什么找你？"
- **不爽事件**（反向）："什么任务让你特别想逃？"——排除同样重要。

**从故事里提炼可迁移能力**，翻译成职场语言，例如：把复杂的事讲清楚 → 结构化表达；琢磨人、协调各方 → 沟通协作；看到数据就想找规律 → 分析洞察；爱从 0 搭东西 → 创造/产品化；见不得粗糙 → 品质把控。点出 2–4 个反复出现的，告诉用户"这几样是你身上稳定的信号"。然后**用三圈图或能力雷达图（`交互与可视化.md` 图 1/2）画出来**。

## 四、把兴趣 + 能力映射到方向
- 给 **2–3 条候选方向**，不钦定一条——早期保留探索空间。
- 每条说清：为什么和他的兴趣+能力匹配、这条路大致长什么样、**第一步怎么用最小成本验证**。

## 五、兴趣靠试不靠想：用实验循环不断迭代
这是把"一过性建议"变成"持续成长"的关键——**兴趣和方向不是在脑子里想清楚的，是用小成本实验试出来、再迭代出来的。**

带用户跑这个循环（每次回访都再跑一轮，衔接 `持续档案.md`）：
> **兴趣假设 → 设计一个 2–4 周的小实验 → 看真实反馈 → 更新对兴趣/能力的判断 → 下一个实验**

- 实验示例：做一个小项目、连写几篇/几条内容、找该领域的人聊一次（信息访谈）、接一个相关的活上手试试。
- 看反馈时问：**做完更想做了还是松了口气？有没有产生成就感？别人的反应如何？** 真喜欢和"想象中喜欢"，一试就见分晓。
- 把每轮实验的结果记进档案——几轮下来，那个模糊的"我好像喜欢 X"会被打磨成"我确认喜欢且擅长 Y"。

元建议：**先广后深**（早期适度试探，但给自己半年到一年的验证期，到点收敛）；**看人 > 看公司**（第一份工作能跟到好团队、学到东西，常比平台名气重要）；建立**"能力账户"意识**（让每段经历都在为某种能力存钱，衔接 `中期规划.md`）。
