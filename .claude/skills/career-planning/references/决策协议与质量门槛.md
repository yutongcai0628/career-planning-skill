# 决策协议与质量门槛

这份协议确保报告给出明确建议和复盘办法。所有完整规划都使用；涉及离职、入职、转行、创业、迁居、降薪或多 offer 时必须完整执行。

## 一、先判断问题类型

| 类型 | 典型情况 | 输出重点 |
|---|---|---|
| 方向探索 | 不知道喜欢什么、适合什么 | 暂定方向 + 2–4 周验证实验，暂不确定长期方向 |
| 可逆决策 | 投递、面试、短期项目、内部沟通 | 先行动换信息，设复盘点 |
| 高成本决策 | 裸辞、入职、转行、迁居、创业 | 明确推荐、前提、换方向条件、退出线和 Z 方案 |
| 紧急风险 | 裁员通知、健康或现金流告急 | 先保安全与选择权，再谈长期最优 |

不要把所有问题都做成利弊表。先找出一个最能改变选择的**关键问题**，例如：“这份工作能否让我在 12 个月内完成一个可对外展示的 AI 产品项目？”

## 二、生成一张决策票据

完整规划的 `#conclusion` 固定包含以下字段；HTML 使用 `.decision-ticket`：

- **本轮问题**：今天究竟要决定或验证什么。
- **决策类型**：方向探索 / 可逆 / 高成本 / 紧急风险。
- **当前建议**：一句话给倾向；证据不足时写“先用一个小项目确认，再定长期方向”。
- **最关键的问题**：答案不同会让建议改变，只写一个。
- **什么时候换方向**：出现什么事实时改选另一条路。
- **先看哪些变化**：在最终结果出现前，观察哪 1–3 个可见变化。
- **复盘日期**：写具体日期或明确事件点，例如“下次绩效沟通后一周”。

方向探索没有 offer 可选时，把“当前建议”写成优先尝试的方向，并说明什么情况需要停止或调整实验。

## 三、证据门槛

每个关键结论标记为以下一种，不用虚构百分比：

- **证据充分**：至少两个不同场景的行为/结果，或用户材料与可靠外部事实相互支持。
- **部分支持**：有一个具体证据，但场景单一或仍有关键缺口。
- **待验证**：只有自述、偏好或推断，尚无真实任务和外部反馈。
- **相互冲突**：证据指向不同结论；并列呈现，说明是时间变化、场景差异还是信息不足。

高成本决策若核心前提仍“待验证”，默认先设计低成本验证，不用漂亮措辞掩盖未知。

## 四、深度咨询的推理门槛

完整规划要让用户看见建议怎样得出。主方向至少走完下面的链条：

**用户经历与约束 → 行业和岗位机制 → 岗位重要性 → 目标能力 → 当前证据与缺口 → 护城河建设 → 行动与复盘**

以下要求全部满足后，建议才具有参考价值：

1. **有个人化诊断**：指出一项由用户具体经历推出来的优势、一项被高估的优势或一项容易忽略的限制。不能把换个名字仍适用于多数人的建议当作核心洞察。
2. **有岗位机制**：说明岗位如何创造价值、在组织中能决定什么、对什么结果负责，以及行业或技术变化会怎样改变它。
3. **有能力倒推**：从关键判断和结果倒推 3–5 项目标能力，再说明用户目前证明到哪一层。
4. **有护城河路径**：指出当前层级、缺失证据、未来 90 天的建设动作和 3–5 年的积累顺序。
5. **有替代方案**：至少说明一个相邻方向，以及主方向在哪种条件下会失去优势。
6. **有验证协议**：每项关键建议说明理由、动作、产物、验收信号和复盘点。无法验证的宏大建议要缩小。

## 五、必须拦截的常见误区

- 用公司名、title 或薪资替代对真实工作、负责人、团队质量和学习环境的判断。
- 列很多优缺点，却没有一个关键问题和明确倾向。
- 把缓解当下焦虑误认为长期更优，把沉没成本误认为留下的理由。
- 用“沟通强、学习快、有审美”等通用形容词宣布护城河已经形成。
- 用行业热度、岗位名称或组织级别直接宣布岗位重要，没有分析价值链、判断权、结果责任和未来变化。
- 罗列“产品思维、商业思维、AI 能力”等抽象词，没有说明要处理的问题、训练项目和下一份证据。
- 用 1–10 分自评或无依据的精确权重制造客观感。
- 把“大师说过”当论据，忽略来源、适用前提和用户自身证据。
- 只有行动清单，没有截止时间、产物、验收信号、切换线和复盘日期。

## 六、交付前质量门槛

以下任一项缺失，完整规划都不算完成：

- [ ] 一句话能读出当前建议或主验证方向。
- [ ] 全文没有“先否定 A，再抬高 B”的对照句；核心建议一遍能读懂。
- [ ] 一句话只讲一件事；专业词第一次出现时有日常解释。
- [ ] 关键判断能追溯到用户证据、可靠外部事实或明确标注的推断。
- [ ] 兴趣来自行为证据；护城河同时写已有证据和缺失证据。
- [ ] 主方向区分行业价值链、当前组织和个人长期发展三层重要性，并说明未来 3 年的变化。
- [ ] 3–5 项能力从岗位的关键判断和结果倒推，每项都有当前证据、能力边界、下一层和证明方式。
- [ ] 护城河写明当前层级、90 天建设动作、1 年资产和 3–5 年放大路径。
- [ ] 至少一条洞察只能从该用户的具体经历和约束得出；删除换个名字仍然成立的空泛建议。
- [ ] 大师透镜有类型、来源状态、用户应用和失效边界，不扮演人物本人。
- [ ] 高成本决策有一个关键问题、换方向或退出的条件、需要先观察的变化和复盘日期。
- [ ] 反脆弱部分覆盖组织变化、裁员、行业下行、技能折旧和 A/B/Z。
- [ ] P1/P2/P3 都有时间、交付物和验收信号，P1 不超过两项。
- [ ] 经授权的档案已增量更新；无法保存时明确说明，没有假装完成。
