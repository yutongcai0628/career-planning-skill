# 中期规划（已有方向，纠结怎么走）

适用对象：工作几年、有了基本方向，但纠结"下一步往哪走""怎么才能突出重围"的人。

中期的主线只有一句话：**如何在未来 3–5 年，形成难以替代的能力组合。** 先明确要积累什么能力，再据此选择公司和岗位，最后设计 3–5 年路径。

## A. 选公司与岗位：大厂 vs 创业

不要泛泛比较优劣，要落到"这个人此刻该选哪个、为什么"。先把取舍摆清：

| | 大厂 | 创业公司 |
|---|---|---|
| 给你的 | 体系化方法论、品牌背书、优质同事、资源、稳定现金流 | 成长速度、责任范围大、全链路视野、上升空间、股权想象 |
| 代价 | 分工较细，责任范围可能偏窄；流程慢，晋升竞争强 | 稳定性较低，资源少；方法可能难以迁移到成熟组织 |
| 适合 | 早期攒方法论和背书；想补"正规军"训练；需要稳定 | 已有方向想快速变全才；想押注一个赛道；能扛风险 |

**决策不该问"哪个更好"，而该问这几件事：**
1. **你现在缺的是哪种资本？** 缺方法论和背书 → 大厂这一站很值；缺独当一面的经历和成长速度 → 创业这一站更划算。
2. **这一站要为壁垒攒什么？** 优先选择能带来目标能力、作品或行业关系的岗位。公司名气单独列为一个参考项。
3. **可逆性**：大厂→创业通常比创业→大厂容易。早期攒背书、后期下场创业，是一条常见且稳的顺序——但不是唯一解，看个人。

警惕两个误区：把大厂的"品牌光环"误当成"自己的能力"；以及为了"快速成长"跳进一个其实在重复低水平劳动的创业坑。

## B. 核心竞争力：形成难以替代的能力组合

这是中期的核心。独特竞争力 ≈ **稀缺性 × 不可替代性**，而单一技能几乎一定会被卷平。真正的壁垒来自**组合**和**复利**。

### 1. 用"交叉"造壁垒（T 型 / π 型人才）
单点上你很难做到全市场第一，但在**两三个领域的交叉点**上你可能是稀缺的。
- 经典组合：技术 + 某个行业的深入认知；设计 + 商业；运营 + 数据；专业能力 + 表达/影响力。
- 帮用户找自己的交叉点：已有能力中，哪两样组合后能形成较少见的价值？这通常是值得继续验证的方向。

### 2. 选"会复利"的能力，避开"会折旧"的能力
- **复利型**（可随时间积累）：判断力、品味、领域认知、人脉与信任、个人品牌、带人和搭系统的能力。
- **折旧型**（容易被替代或过时）：单一工具的熟练度、靠加班堆出来的体力活、做完后没有留下方法或作品的纯执行任务。
- 给建议时反复问："你现在每天做的事，三年后还值钱吗？是在往复利账户里存，还是在折旧？"

### 3. 壁垒的常见来源
稀缺的经历 / 数据、深的领域纵深、独特的能力组合、网络效应（人脉与口碑）、以及"做过别人没机会做的事"。判断一个选择能不能造壁垒，就看它能不能给你这几样里的至少一样。

## C. 路径构建：什么样的选择能帮你攒出这种能力

把职业选择放进 3–5 年路径中主动设计。可以使用两个工具：

### 1. "能力账户"思维
把每一份工作和每一个项目都看成一次能力投资：**它能否同时带来收入和目标能力？如果只有收入，这种状态可以持续多久？** 中期阶段要优先保留能力增量，同时守住现金流底线。

### 2. 倒推法（从未来目标设计现在）
- 先问：**3–5 年后，你想成为哪种稀缺的人？**（用 B 帮他描述出那个画像）
- 再问：那种人身上有哪些能力 / 经历 / 标签？
- 最后倒推：哪份工作、哪个岗位、哪类项目能给你这些？据此去选、去争取，甚至主动设计（争取某个项目、申请轮岗、卡准跳槽时机）。
- 跳槽的判断标准也由此而来：**这一跳是在补齐画像里缺的那块拼图，还是只是涨薪 / 逃避？** 横向重复同样的能力不叫成长。

## D. 越走越高：突破天花板与实现个人价值
很多人到了职业中期，会感觉发展停住，也说不清每天忙碌的价值。处理这个问题分两步：

### 1. 先诊断卡在哪种天花板（三种解法完全不同）
- **能力天花板**：你自己还不够强。→ 解法是补能力、找更难的问题练（呼应"专挑最难的问题做"）。
- **平台天花板**：公司、业务或行业缺少增长空间，个人能力很难继续转化为更大责任。解法是寻找仍有真实问题和发展空间的平台。
- **结构天花板**：晋升通道受限，或该职能本身缺少更高责任层级。解法是评估横向转岗、更换业务或调整能力组合。
平台和结构问题需要与个人能力问题分开诊断，避免把外部限制全部归因于自己。

### 2. 向上突破的几个真正杠杆
- **从“把事做好”到“定义做什么”**：执行者很多，能定义问题、定方向的人稀缺。职位越高，判断的重要性越高。
- **从个人贡献到放大影响**：带人、搭系统、对外影响力——让你的产出不再受限于自己的工时。
- **争取更大的盘子和话语权**：主动争取更重要的项目和更靠近核心业务的位置。

### 3. 把个人价值纳入路径判断
只盯职级和薪水，可能会把人带到一条不喜欢的路上。需要继续问：**你想成为什么样的人？想留下什么？什么事让你觉得有意义？** 再从这个答案倒推下一步，同时把收入、职级、影响力和作品放在同一张图里比较。

## 给中期建议时的姿态
- 建议必须落到**这个人具体的能力交叉点和目标画像**上。“提升核心竞争力”还需要进一步写成具体能力、项目和验收信号。
- 帮他把模糊的焦虑翻译成一个清晰的取舍：你这一站是去攒 X，所以选项里能给 X 的那个更值。
- 诚实指出沉没成本陷阱、光环错觉、和"看起来忙其实在折旧"的状态。
