# 中期规划（已有方向，纠结怎么走）

适用对象：工作几年、有了基本方向，但纠结"下一步往哪走""怎么才能突出重围"的人。

中期的主线只有一句话：**如何在未来 3–5 年，形成难以替代的能力组合。** 三个子问题——选公司 / 建壁垒 / 构路径——都服务于这个目标。给建议时不要把它们当三道独立的题，而是一条线：**先想清要积累什么能力（B），再据此选公司和岗位（A），并主动设计路径（C）。**

## A. 选公司与岗位：大厂 vs 创业

不要泛泛比较优劣，要落到"这个人此刻该选哪个、为什么"。先把取舍摆清：

| | 大厂 | 创业公司 |
|---|---|---|
| 给你的 | 体系化方法论、品牌背书、优质同事、资源、稳定现金流 | 成长速度、责任范围大、全链路视野、上升空间、股权想象 |
| 代价 | 分工细→易成螺丝钉、流程慢、晋升拥挤、可替代性高 | 不稳定、资源少、风险高、可能学到一身"野路子" |
| 适合 | 早期攒方法论和背书；想补"正规军"训练；需要稳定 | 已有方向想快速变全才；想押注一个赛道；能扛风险 |

**决策不该问"哪个更好"，而该问这几件事：**
1. **你现在缺的是哪种资本？** 缺方法论和背书 → 大厂这一站很值；缺独当一面的经历和成长速度 → 创业这一站更划算。
2. **这一站要为壁垒攒什么？**（回到 B）选能给你目标能力的那个，而不是名气大的那个。
3. **可逆性**：大厂→创业通常比创业→大厂容易。早期攒背书、后期下场创业，是一条常见且稳的顺序——但不是唯一解，看个人。

警惕两个误区：把大厂的"品牌光环"误当成"自己的能力"；以及为了"快速成长"跳进一个其实在重复低水平劳动的创业坑。

## B. 核心竞争力：形成难以替代的能力组合

这是中期的核心。独特竞争力 ≈ **稀缺性 × 不可替代性**，而单一技能几乎一定会被卷平。真正的壁垒来自**组合**和**复利**。

### 1. 用"交叉"造壁垒（T 型 / π 型人才）
单点上你很难做到全市场第一，但在**两三个领域的交叉点**上你可能是稀缺的。
- 经典组合：技术 + 某个行业 know-how；设计 + 商业；运营 + 数据；专业能力 + 表达/影响力。
- 帮用户找自己的交叉点：已有能力中，哪两样组合后能形成较少见的价值？这通常是值得继续验证的方向。

### 2. 选"会复利"的能力，避开"会折旧"的能力
- **复利型**（可随时间积累）：判断力、品味、领域 know-how、人脉与信任、个人品牌、带人和搭系统的能力。
- **折旧型**（容易被替代或过时）：单一工具的熟练度、靠加班堆出来的体力活、纯执行且不沉淀的事。
- 给建议时反复问："你现在每天做的事，三年后还值钱吗？是在往复利账户里存，还是在折旧？"

### 3. 壁垒的常见来源
稀缺的经历 / 数据、深的领域纵深、独特的能力组合、网络效应（人脉与口碑）、以及"做过别人没机会做的事"。判断一个选择能不能造壁垒，就看它能不能给你这几样里的至少一样。

## C. 路径构建：什么样的选择能帮你攒出这种能力

把职业当成**主动设计**，而不是被动接 offer。两个工具：

### 1. "能力账户"思维
把每一份工作、每一个项目都看成一次存款或取款：**它在为我的目标能力存钱，还是只在换薪水（出卖时间）？** 理想的选择是钱和能力都给你；只能二选一时，中期阶段优先选给能力的——前提是现金流扛得住。

### 2. 倒推法（从终局设计现在）
- 先问：**3–5 年后，你想成为哪种稀缺的人？**（用 B 帮他描述出那个画像）
- 再问：那种人身上有哪些能力 / 经历 / 标签？
- 最后倒推：哪份工作、哪个岗位、哪类项目能给你这些？据此去选、去争取，甚至主动设计（争取某个项目、申请轮岗、卡准跳槽时机）。
- 跳槽的判断标准也由此而来：**这一跳是在补齐画像里缺的那块拼图，还是只是涨薪 / 逃避？** 横向重复同样的能力不叫成长。

## D. 越走越高：突破天花板与实现个人价值
很多人到中期最大的痛不是"不知道做什么"，而是"感觉到顶了、上不去了，也不知道为什么忙"。处理这个，分两步：

### 1. 先诊断卡在哪种天花板（三种解法完全不同）
- **能力天花板**：你自己还不够强。→ 解法是补能力、找更难的问题练（呼应"专挑最难的问题做"）。
- **平台天花板**：公司/业务/行业本身没空间了，再强也涨不动。→ 解法是换平台，别在没水的井里挖。
- **结构天花板**：位置被占着、晋升通道堵死、或这条路天然没上升空间（结构性的）。→ 解法是横向换赛道或换打法，硬熬最亏。
**别把平台/结构天花板误当成自己不行**——很多人因此过度自我怀疑、白白消耗。先帮他分清。

### 2. 向上突破的几个真正杠杆
- **从"把事做好"到"定义做什么"**：执行者很多，能定义问题、定方向的人稀缺。越往上，价值越在判断而非勤奋。
- **从个人贡献到放大影响**：带人、搭系统、对外影响力——让你的产出不再受限于自己的工时。
- **争取更大的盘子和话语权**：主动要更重要的项目、更靠近核心业务的位置，而不是被动等分配。

### 3. 把"个人价值"接进来，别爬错墙
"越走越高"如果只盯职级和薪水，很容易爬到顶才发现爬错了墙。帮用户把更深的问题接进职业选择：**你想成为什么样的人？想留下什么？什么事让你觉得有意义？** 个人价值的实现，往往是职级、影响力、作品、对他人的意义这几样的合体——钱和 title 只是其中一部分。倒推：从"你想实现的那种价值"出发选下一步，而不是只往薪资高的地方爬。

## 给中期建议时的姿态
- 一定要落到**这个人具体的交叉点和目标画像**上，别给"打造核心竞争力"这种正确的废话。
- 帮他把模糊的焦虑翻译成一个清晰的取舍：你这一站是去攒 X，所以选项里能给 X 的那个更值。
- 诚实指出沉没成本陷阱、光环错觉、和"看起来忙其实在折旧"的状态。
