# 标杆与思维透镜（用榜样和大师框架来辅助规划）

这个模块给规划提供"外部参照"：用厉害的人怎么想（思维透镜）、怎么走（标杆路径）来照亮用户的选择。

**贯穿底线（务必遵守）：**
- **不编造**：引用名人框架只用公开、确证的内容；绝不杜撰他们的话、事迹或履历细节。不确定就说不确定，或用 WebSearch 查证。
- **不迷信、警惕幸存者偏差**：名人的路径**不是可照抄的公式**——时代红利、运气、不可复制的起点占很大比重。把他们当**灵感和决策透镜**，而不是"照着做就能成"。永远落回用户自己的处境。
- **不 cosplay**：是"用第一性原理帮你想这件事"，不是模仿马斯克的语气说话。

何时调用本模块：用户问"有没有榜样/标杆参照""帮我用第一性原理/长期主义想想""XX 是怎么走到那一步的"，或在重大决策卡住、需要换个思考框架时主动拿出来。

## 一、名人思维透镜（决策框架工具箱）

每个透镜 = 一句话内核 + 怎么套到职业规划 + 可直接问用户的话。按当下问题挑 1–2 个用，不要一次全上。

### 第一性原理（常与马斯克关联）
- **内核**：别从"同行都这么做"类比，回到根上问"事情的本质是什么、什么是真正必须的"。
- **用法**：破除从众。当用户说"大家都去考公/进大厂，所以我也……"时，拆掉假设：你到底要什么？这条路的哪些环节是真的必需，哪些只是别人都这么干？
- **问**："如果忘掉别人都怎么选，只从你真正想要的东西出发，这件事最该怎么安排？"

### 交叉点 + 做减法（常与乔布斯关联）
- **内核**：独特性来自不同领域的交叉（如科技 × 人文）；卓越来自专注，"决定不做什么"和决定做什么一样重要。
- **用法**：直接强化 skill 的"交叉造壁垒"。帮用户找自己的交叉点；并逼他做减法——精力有限，砍掉哪些才能让主线长出来。
- **问**："你身上哪两样东西叠在一起别人很难复制？为了让它长起来，你愿意先不做哪些事？"

### 后悔最小化 + 长期主义（常与贝索斯关联）
- **内核**：把自己投射到 80 岁，回头看哪个选择你不会后悔；用足够长的时间尺度做决定。
- **用法**：专治重大、纠结、可逆性低的决策（要不要裸辞创业、要不要换赛道）。把短期得失拉长看。
- **问**："站到 80 岁回头看这个决定，哪个选项你更不会后悔？"

### 职业即创业 + ABZ 规划（常与里德·霍夫曼 / LinkedIn 创始人关联）
- **内核**：把自己的职业当一家创业公司经营——永远处于"beta 测试"、持续迭代。做 ABZ 规划：A 是当前主路径，B 是发现更好机会时随时能切的备选，Z 是万一全崩了的兜底退路。
- **用法**：专治"必须一步选对"的焦虑。职业不是一锤定音，而是边走边调。帮用户同时握住 A 和 B，并确认 Z 让他敢于冒险。
- **问**："如果当前这条 A 路走不通，你的 B 计划是什么？最坏情况下能接住你的 Z 又是什么？"

### 杠杆 + 特定知识（常与纳瓦尔关联）
- **内核**：用内容、代码、资本这类"零边际成本的杠杆"放大自己；积累别人难以教、靠你独特经历长出来的"特定知识"。
- **用法**：尤其适合内容/创作/技术方向的人。帮用户想：你能用什么杠杆把一份努力放大成一千份？你的"特定知识"是什么？
- **问**："你做的事，是只能一对一交付，还是能借内容/产品放大到很多人？"

### 复利你自己 + 趁早过度自信地下注（常与山姆·奥特曼 / OpenAI、YC 关联）
- **内核**：人生最大的杠杆是"复利"——选那些能让你的能力、声誉、人脉随时间指数级累积的事；同时趁年轻多冒险、对自己抱有近乎过度的自信（但要快速纠错）。
- **用法**：和 skill 的"复利vs折旧"咬合。帮用户分辨哪些选择是线性出卖时间、哪些会复利；并鼓励在容错成本最低的早期多下注、多试。
- **问**："你现在做的事，是会随时间复利，还是每年都从零开始？哪个选择五年后回报最陡？"

### 别竞争，做垄断 + 逆共识（常与彼得·蒂尔关联）
- **内核**："竞争是留给失败者的"——在红海里和所有人拼，利润和价值都被卷光；真正的机会是找到一个你能独占的小生态。配套的提问是："有哪个重要的真相，很少有人认同你？"
- **用法**：强化 skill 的"人无我有"。帮用户别一头扎进千军万马的热门赛道，而是找自己能成为"小池塘里的大鱼"、再慢慢扩张的位置。
- **问**："与其在最热的赛道里当第 1000 名，有没有一个细分领域你能当第 1 名？"

### 做困难而有趣的事 + 顺着真实的好奇心（常与保罗·格雷厄姆 / YC 关联）
- **内核**：伟大的工作往往长在"你天然擅长 × 你深感好奇 × 这件事足够重要"的交点上；与其追逐看起来体面的路，不如顺着真实的好奇心去做困难的事。
- **用法**：帮迷茫的人回到"什么问题让你忍不住想钻进去"，而不是"什么职业听起来高级"。好奇心是最好的指南针，也最难伪装。
- **问**："有没有一类问题，你会不为任何回报、纯粹因为好奇就想搞明白？"

### 发展稀缺技能组合 + 把自己放进机会密集处（常与马克·安德森 / a16z 关联）
- **内核**：与其纠结"追随热情"，不如发展一套**既有价值又稀缺**的技能组合，并主动把自己放进机会最密集的环境（高增长公司、对的城市、对的圈子）——机会本身会带来运气。
- **用法**：帮用户从"我喜欢什么"转向"我能练出什么别人没有的组合、以及哪里机会最多"。强调环境对一个人成长的放大作用。
- **问**："你想练的那套稀缺技能组合是什么？哪种环境会让它增值最快？"

### 长期信念 + 在煎熬中成长（常与黄仁勋 / NVIDIA 关联）
- **内核**：真正的壁垒常来自"在没人看好时，对一个方向保持十年级别的信念"；而韧性与格局，恰恰是在痛苦和挫折里长出来的，舒适养不出强者。
- **用法**：用在两处——帮用户判断有没有一个值得长期押注的方向（而非追风口），以及重新看待当下的挫折（是消耗，还是在锻造别人学不来的韧性）。
- **问**："有没有一件事你愿意在三五年看不到回报时仍坚持？最近的挫折，是在掏空你，还是在练你？"

### 职业是攀登架，不是梯子（常与谢丽尔·桑德伯格 / Meta 前 COO 关联）
- **内核**：职业不是一架只能向上爬的梯子，而是一个"攀登架"——横向移动、绕路、甚至暂时下移都可能通向更高处；机会比头衔重要，所谓"有人给你火箭上的座位，先上去，别问坐哪个"。
- **用法**：专治"只盯着线性升职、不敢横跳"的人。帮用户看到一次横向/换赛道的移动，可能比原地等晋升更划算；遇到高速成长的机会，先上车再说。
- **问**："如果不把职业想成一条只能往上的梯子，有没有一次横向移动能让你看到更大的风景？"

### 专挑最难的问题做（常与苏姿丰 Lisa Su / AMD CEO 关联）
- **内核**：在所有能做的事里，主动选"最难的那个"——难的问题对手少、逼你成长快、做成了壁垒最高。她带 AMD 从濒死翻盘，靠的正是不回避硬仗。
- **用法**：当用户在"舒服但没成长"和"难但能学到东西"之间犹豫时，提醒"难"往往就是稀缺性的来源。帮他识别哪个选择是"难而正确"。
- **问**："摆在你面前的选项里，哪个最难、但做成了最值钱？你是不是在回避它？"

### 认准长期愿景，被拒一百次也熬下去（常与梅勒妮·珀金斯 / Canva 创始人 CEO 关联）
- **内核**：她融资被 100 多位投资人拒绝才做成 Canva——清晰而宏大的长期愿景 + 近乎固执的坚持，是把一个不被看好的方向熬成现实的关键。
- **用法**：用在用户认准了方向却频频受挫、想放弃时。帮他区分"被现实证伪、该转向"和"只是还没熬到拐点"。（务必配合幸存者偏差提醒，不盲目灌鸡汤。）
- **问**："你受的挫，是这个方向被证明错了，还是你只是还没坚持到它该成的那一刻？"

### 重新定义失败（常与莎拉·布雷克利 Sara Blakely / Spanx 创始人关联）
- **内核**：她父亲从小问她"你这周失败了什么？"——把"失败"重新定义成"有没有去尝试"，没尝试才是真失败。这让冒险的心理成本大大降低。
- **用法**：专治怕犯错、怕丢脸而不敢迈步的人（尤其完美主义者）。把"会不会搞砸"换成"我有没有去试"，行动门槛立刻降下来。
- **问**："如果把'失败'重新定义成'这周我有没有勇敢试一件事'，你这周的答案是什么？"

### 把痛点和不公变成事业 + 反向下注（常与惠特尼·沃尔夫·赫德 / Bumble 创始人 CEO 关联）
- **内核**：她离开 Tinder（经历一场不愉快的纠纷）后创办 Bumble，把一个反共识的洞察（让女性先开口）做成公司，30 岁出头成为最年轻的白手起家女性亿万富翁之一。痛点和不公，可以是你下一个事业的起点。
- **用法**：帮那些"从一段糟糕经历/被亏待里走出来"的人，把愤怒和痛点转化成"一个很多人都有、却没人好好解决的问题"。也强化反共识——别人觉得理所当然的地方，常常正是机会。
- **问**："你经历过的哪个痛点或不公，其实是很多人都有、却没人认真解决的问题？"

### 先有受众，再有产品：从内容长出品牌（常与艾米莉·维斯 Emily Weiss / Glossier 创始人关联）
- **内核**：她一边做助理一边写美妆博客 Into The Gloss，先靠内容聚起一个高黏性社群，再把社群变成品牌 Glossier。**先有受众、再有产品**，是内容时代一条很真实的路径。
- **用法**：**特别适合做内容/自媒体的人**（和很多用户的甜区重合）。帮他看到：现在攒的粉丝和内容不只是"作品"，可能是未来产品/品牌的地基——先验证有没有人听你，再想卖什么给他们。
- **问**："你现在的内容和受众，有没有可能不止是作品，而是某个产品或品牌的种子？"

### 从实习生干到 CEO：在一处深耕到极致（常与玛丽·巴拉 Mary Barra / 通用汽车董事长兼 CEO 关联）
- **内核**：她 18 岁作为实习生进入通用，一路做到 CEO——证明"在一家公司/一个领域深耕到无可替代"也是一条真实的顶级路径，不是只有跳来跳去才叫成长。
- **用法**：平衡本 skill 里偏"多跳、找交叉"的倾向。提醒有些人更适合"深耕型"：在一个地方把信任、专业、关系攒到极厚。帮用户判断自己是"跳跃型"还是"深耕型"。
- **问**："你更像靠不断换环境成长，还是靠在一个地方深耕到别人离不开你？哪种更像你？"

### 成长与舒适无法共存（常与金尼·罗梅蒂 Ginni Rometty / IBM 前 CEO、典型职业经理人关联）
- **内核**：她的名言"成长和舒适，永远无法共存"。几乎每一次有意义的成长，都发生在你感到不适、没十足把握的时刻。
- **用法**：当用户因为"现在挺舒服/有点怕"而不敢接一个有挑战的机会时，用这把尺子。把"我还没准备好"翻译成"这正是会让我成长的地方"。
- **问**："这个让你犹豫的机会，是真的不适合你，还是只是因为它让你不舒服？"

（可按需继续扩展其他公认框架，但每个都要能落到"怎么帮用户做决定"，否则就是名人名言堆砌，没用。男女、老中青、创始人/职业经理人、不同行业尽量保持多元，别让"导师天团"清一色。）

## 二、粘贴履历分析（用户提供某个榜样的简历/领英）

**不要自动爬领英**（违反其条款、易致封号、技术脆弱）。正确方式：请用户把他佩服的人的公开履历/领英内容**粘贴**进来，再分析。

分析步骤：
1. **画出轨迹**：把这个人的关键节点按时间排出来——每一步从哪到哪、跨度多大。
2. **找拐点**：哪几步是真正改变命运的跳跃？当时他攒下/赌对了什么？
3. **拆"可复制" vs "靠运气/时代"**：诚实区分——哪些是方法（可学），哪些是不可复制的起点、人脉、时代红利。**这一步最重要，能防止用户盲目照抄。**
4. **对照用户**：这个人的可复制部分，哪些用户也能走？用户的处境和他差在哪、起点不同在哪？
5. **提炼 1–3 条可迁移的启示**，落成用户能用的动作，而不是"你也要像他一样努力"。

提醒用户：你看到的是一个**幸存者**的故事，多看几个同方向的人会更可靠。

## 三、联网搜公开榜样（WebSearch）

当用户想要某方向的标杆参照、但手头没有具体人选时，用 `WebSearch` 搜**公开信息**（访谈、报道、公开演讲、公开履历），而不是抓私人数据。

要点：
- 搜"<方向> 从业者 职业路径 / 访谈 / 怎么入行"之类，找几个公开案例，而非只看一个。
- **标注来源和不确定性**：是公开报道里说的，还是你的推断，要分清。查不到就说查不到，不要脑补。
- 同样做"可复制 vs 靠运气/时代"的拆解，并提醒幸存者偏差。
- 搜来的信息要**服务于用户的决策**（"所以对你意味着……"），不是堆素材。

## 四、内置标杆路径库（不依赖联网的常见方向模板）

下面是几条常见方向的**典型成长路径骨架**，作为快速参照。它们是"常见形态"，**不是必经之路**——用来给用户一个地图感，再结合他的具体情况调整。

### 内容 / 新媒体增长
入行（运营某账号/小编，学选题·写作·数据）→ 独立操盘一个号或一条线（对增长指标负责）→ 内容/增长负责人（带团队、定策略、跨渠道）→ 品牌内容总监 / 自由创作者 / 自己做 IP 或公司。
关键复利：内容判断力、增长方法论、个人品牌与作品集。常见拐点：第一次独立对一个增长数字负责。

### 产品经理
入行（执行需求、写文档、跑数据）→ 独立负责一个模块/功能 → 负责一条产品线 → 产品负责人 / 0-1 开创新业务。
关键复利：判断力与品味、对用户和业务的理解、跨团队推动力。常见拐点：第一次独立背一个业务结果。

### 设计 / 创意
入行（执行设计，练手感和规范）→ 独当一面接项目 → 资深/带方向（定视觉语言、影响决策）→ 设计负责人 / 独立设计师 / 创意合伙人。
关键复利：审美与品味、作品集、把设计和商业目标连起来的能力。常见拐点：从"接需求做图"到"参与定义要做什么"。

### 技术 / 工程
入行（写好代码、补工程素养）→ 独立负责模块 → 资深/技术骨干（做架构、定方向）→ 架构师 / 技术管理 / 技术创业。
关键复利：技术判断力、领域纵深、解决复杂问题的口碑。常见拐点：从"实现别人定的方案"到"定方案"。

（其他方向可现场推演，套路相同：执行 → 独当一面 → 定方向/带人 → 更大的盘子或自立。重点是帮用户看清**自己现在在哪一格、下一格要攒什么**，并回到"会复利吗、是不是你的甜区"。）
