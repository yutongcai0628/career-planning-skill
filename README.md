# 职业规划 Skill
<img width="1622" height="896" alt="career-planning-skill" src="https://github.com/user-attachments/assets/1012e93a-25bf-4293-9343-dbfb1bdf5e31" />

这是一个面向 Claude Code、Codex、Kimi、Cursor Agent 及其他兼容 Agent Skills 的职业规划 Skill。

它适合处理职业迷茫、转岗转行、离职与 offer 决策、能力提炼、长期发展和职业风险等问题。

## 它能帮你做什么🤔

- 从做过的事情、产生的结果和他人反馈中提炼已经被证明的能力。
- 分析岗位在行业、组织和个人长期发展中的价值。
- 判断哪些工作值得长期重复，哪些方向只是短期看起来热门。
- 比较 offer、转岗、离职或继续留下的收益、代价与验证条件。
- 给出一个主路径、一至两个相邻路径，以及保护现金流和生活的安全底座。
- 把建议转成有时间、产物和验收信号的 90 天行动计划。
- 完整咨询开始时先确认你是否有飞书 CLI；没有或不确定时，回答后自动生成并持续更新本地 HTML 职业报告。
- 飞书 CLI 可用且已授权时，可以选择本地 HTML 或带主画板的飞书文档。

你可以直接问：

```text
我对工作和未来很迷茫，不知道自己真正擅长什么，该把什么当成长期发展的方向。

我该不该离职？我在现在公司待了 18 个月，手里有一个新 offer。

这是我的简历和 JD，帮我判断这个岗位是否适合我。

我想从运营转产品经理，但担心收入下降，应该怎么验证？

继续我的职业档案：我完成了上次的行动计划，也遇到了一个新问题。
```
- 不需要一次性交代完整背景。可以先说当前问题，也可以提供简历片段、JD、offer 条款、薪资结构、面试反馈或自己整理的数据。
- 信息不足时，再用 1–3 道选择题确认那些可能改变结论的信息。你回答后，它会生成所选格式的完整报告。

## 它怎样形成建议💡

Skill 不使用简单的性格标签、热门行业排行榜或随意打分替你做决定。一次完整规划通常会依次处理：

1. 明确这次真正需要决定的问题。
2. 区分用户提供的事实、公开资料、推断与未知信息。
3. 从经历和结果中提炼兴趣方向、能力证据与能力边界。
4. 分析岗位怎样创造价值，以及未来 3–5 年可能发生的变化。
5. 判断长期兴趣、现实约束与可携带的职业资产。
6. 给出主路径、相邻路径和 ABZ 风险预案。
7. 形成 90 天行动计划和下一次复盘条件。

信息足够时，Skill 会给出明确倾向；信息不足时，会设计成本较低的验证实验，而不是同时列出很多方向让用户自己猜。

## 大师透镜与联网核验🔍

当前 Agent 具备 Web Search、浏览器或网页读取能力时，Skill 会在公开网络中定向检索与当前问题有关的创业者、产品负责人、设计师、投资人、管理学者和行业专家材料，并核验实际采用的框架。它不会声称穷尽整个互联网，也不会把搜索摘要当作事实依据。

检索会优先使用：

1. 本人著作、官网、课程、公开演讲和署名文章。
2. 本人接受的正式访谈、播客或机构发布的完整记录。
3. 能被多个可靠来源相互印证的归纳。
4. 人物或公司的经历类比。

每次完整规划最多选择两个真正相关的透镜，并区分正式框架、归纳启发式和案例类比。报告会注明来源、用途和失效边界，不模仿名人语气、不杜撰引语，也不暗示当事人认可这份建议。

如果当前 Agent 不能联网，Skill 会明确标注未现场核实，不会自行补全动态履历、公司数据或人物引语。

## 你会拿到什么✅

完整规划包含：

- 当前问题与核心判断
- 经历和能力证据
- 岗位重要性与长期变化
- 兴趣到岗位的证据链
- 能力账户与职业护城河
- 大师透镜及来源
- 主路径、相邻路径与 ABZ 预案
- 90 天行动 Roadmap
- 复盘日期和改变方向的条件

匿名页面示例见 [职业决策报告示例](examples/职业决策报告示例.html)。

### 本地 HTML

HTML 是完整职业规划的默认交付物，可以直接用浏览器打开，适合长期保存、打印或导出 PDF。报告打开时不会自动加载外部图片、脚本、字体、视频或追踪地址。

飞书不可用时，Skill 会在当前工作区被忽略的 `职业档案/` 中自动生成 HTML 与配套状态文件，用于下次增量更新。它不会把整段聊天原样写入档案；用户明确说不要保存时只在对话中交付。

### 飞书文档

完整咨询开始时，Skill 会先问你是否有飞书 CLI。你回答有之后，它会检查 CLI、飞书文档能力和授权状态；验证通过才会让你选择：

- 本地 HTML
- 飞书文档

选择飞书后，Skill 会持续更新同一篇文档。首次完整档案会使用统一的 `1.`–`8.` 章节编号、独立短段落、原生要点/编号列表和必要的对比表格，并配置 2–3 张分别解释核心判断、兴趣到岗位证据、长期路径、岗位生态或 ABZ 的画板。每张画板都会在交付前导出预览并检查可读性；大段文字堆叠、少于两张有效画板、纯文字文档或空白画板都不算完成。只有用户明确要求“两种都要”时才会同时维护两份。

持续更新发生在用户再次调用 Skill 并提供新进展时。Skill 不会在后台监听、自动记忆或自行发送提醒。

## 隐私与使用边界⚠️

- 建议先隐去身份证号、电话、住址、银行卡、公司机密、客户数据和未公开业务信息。
- 联网检索只使用完成核验所需的最少关键词，例如岗位、行业、公开人物、框架或公开公司名。姓名、邮箱、电话、完整简历、私人职业档案、精确住址、未公开雇主/项目/客户信息不得写入搜索词。
- 公司经营、融资、裁员、薪资、法规和行业数据等动态信息，需要通过可靠公开来源核实；无法核实时会标明不确定性。
- 本地 HTML 不会自动联网，但咨询阶段可以在宿主提供能力时使用 Web Search。
- 本地职业档案只写入当前工作区被 Git 忽略的 `职业档案/`；写入飞书或其他外部位置前必须由用户选择并完成授权。
- 输出属于职业规划与决策支持，不构成法律、劳动争议、签证、投资、税务、医疗或心理健康意见。

## 安装

安装时请保留完整的 Skill 目录，不要只复制 `SKILL.md`。其中的 `references/`、`assets/` 和 `scripts/` 是职业分析与 HTML 报告生成所必需的。

### 使用 Skills CLI

运行下面的命令，并按提示选择要安装到的 Agent：

```bash
npx skills add https://github.com/yutongcai0628/career-planning-skill --skill career-planning
```

也可以一次安装到 Claude Code、Codex、Cursor 和 Kimi Code：

```bash
npx skills add https://github.com/yutongcai0628/career-planning-skill --skill career-planning \
  -a claude-code -a codex -a cursor -a kimi-code-cli
```

### 手动安装

下载本仓库后，将 `.claude/skills/career-planning/` 整个文件夹复制到对应位置：

| Agent | 安装位置 |
|---|---|
| Claude Code | `~/.claude/skills/career-planning/` |
| Codex | `~/.codex/skills/career-planning/` |
| Cursor | `~/.cursor/skills/career-planning/` |
| Kimi Code | `~/.kimi-code/skills/career-planning/` |

其他兼容 [Agent Skills](https://agentskills.io) 的平台，请按平台说明导入同一个完整文件夹。

复制完成后请开启一个新会话。如果 Agent 没有识别到 Skill，请重启当前 Agent 后再试。

安装后可以这样开始：

```text
使用 career-planning skill 帮我做一次职业规划。
```
